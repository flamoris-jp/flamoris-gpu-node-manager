# flamoris-gpu-node-manager v1.2.2

このリポジトリ自身のUpdater配布物とカタログを公開するパッチ版です。amd64/arm64向け配布物はカタログから個別取得できます。初回設定、GPU/モデル動作、実機への導入は別の作業です。既存の集中配布は上書きしません。詳しくはdocs/UPDATER.mdを参照してください。

Empty runtime directories now allow Web startup and initial configuration; missing directories and invalid profiles remain errors. No runtime is activated on startup.
